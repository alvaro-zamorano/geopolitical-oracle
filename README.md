# Geopolitical Oracle

A **public track record** of geopolitical forecasts and their financial implications — predictions logged transparently, with outcomes you can check over time.

🔗 **Live:** https://geopolitical-oracle.vercel.app

## Idea

Anyone can sound smart about world events after the fact. Geopolitical Oracle records calls *before* they resolve and keeps the scoreboard public — accountability over punditry.

## Features

- Timeline of dated, falsifiable geopolitical calls
- Financial-market implications attached to each call
- Transparent, public-facing track record

## Tech stack

HTML · JavaScript · CSS, deployed on Vercel

## Run locally

Clone the repo and open `index.html`, or serve the folder with any static server (e.g. `npx serve`).
